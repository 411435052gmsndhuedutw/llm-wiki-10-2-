# Agent 評估：測試流程，不只看最後答案

## 為什麼需要執行紀錄？

OpenAI 的 Agent 評估指南介紹 traces 用來檢視一次流程中的模型呼叫、工具、護欄與交接；當成功標準明確後，重複資料集與 evaluation runs 可用來比較流程變更。[S5](../raw/sources.md#s5--evaluate-agent-workflows)

對課程測驗 Agent，單看「題目看起來合理」不足以驗收整條流程。

## 建議的題目檢查

- 有唯一 ID、非空題幹與選項。
- 有且只有一個最佳答案。
- 正解與解說能回指證據卡。
- 講義與網路補充標籤沒有混淆。
- 覆蓋範圍和專案設定相符。
- 跳過題目會進入正確課程的錯題庫。

## 建議的流程紀錄

記錄專案、資料模式、選取範圍、來源 ID、題目驗證結果、使用者選擇的回饋模式、答題分支，以及匯出檔案的內容清單。避免在示範紀錄中放入真實私人講義。

## 停止條件

沒有可支持題目的證據就停止該題生成；驗證失敗題目經有限次修正仍未通過時，應排除並列入待人工確認，而不是假裝成功。
