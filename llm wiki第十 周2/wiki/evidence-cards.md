## 依據證據卡產生的示範題

**題目：**依 ReAct 研究的摘要，交替產生行動的主要作用為何？

- A. 讓模型完全不需要外部資訊。
- B. 讓模型能與外部來源或環境互動，並取得後續決策所需的觀察。
- C. 保證每次回答都正確。
- D. 讓所有任務都必須呼叫相同工具。

**正解：**B  
**解說：**研究描述 actions 作為與外部來源或環境互動的介面；它沒有宣稱 ReAct 能保證正確。  
**來源：**[S2](../raw/sources.md#s2--react-synergizing-reasoning-and-acting-in-language-models)，Abstract。

## 題目級檢查結果

| 檢查 | 結果 |
|---|---|
| 題幹能否被來源支持 | 通過 |
| 是否只有一個最佳答案 | 通過：B |
| 正解是否有明確依據 | 通過：S2 Abstract |
| 是否含未證實的保證語句 | 通過：選項 C 為干擾項，解說明確排除 |
| 來源類型是否清楚 | 通過：標示為深入模式的外部來源 |

這是人工走查的範例，不是由可執行的 AI 測驗程式產生或評分。
